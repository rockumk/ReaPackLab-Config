ReaPackLab Administrator Configuration Generator

Create one human-editable ReaPackLab.ini file. Everything runs locally in your browser; nothing is uploaded.

1. Versions

Increase after adding or removing repositories. ReaPackLab applies the new list and synchronizes.

Increase to synchronize packages again without changing the repository list.

The numbers are independent; they do not need to match. When neither increases, checking the hosted configuration does not trigger a package sync. Teacher Mode's Force Sync will be implemented in the extension and affects only that computer.

2. Teacher Mode password

Enter a password to create a salted verifier. Minimum 6 characters (8+ recommended). The password itself is never included in the configuration.

When you import an existing configuration, you can leave both password fields blank to keep its existing verifier. To change the password, enter and confirm the new password.

Password derivation: PBKDF2-HMAC-SHA-256, 600,000 iterations, random 32-byte salt, 32-byte hash.

3. Repository list

One entry per line, all in one text field. Paste plain https://.../index.xml URLs directly—no name or repository= prefix needed. Prefix x to unsubscribe without removing any installed packages, or - to uninstall packages owned by that repository and unsubscribe. For example, xhttps://.../old/index.xml or -https://.../unwanted/index.xml. Blank lines and # comments are allowed.

Plain URLs subscribe; xURL unsubscribes with no package removal; -URL uninstalls packages owned by that repository and unsubscribes. No entry may appear twice.

4. Package cleanup options

When a previously installed package is no longer offered by a subscribed repository, select whether it should be removed during a successful managed sync. This is separate from xURL and -URL repository directives.

Deployment: Older ReaPackLab versions reject the new [Options] section and xURL prefix. Deploy the updated extension to your Macs before publishing a newly generated configuration.

5. Generated configuration

Generate, inspect, copy, or download the single configuration file. This is plain text and can be edited manually after downloading.

Generate to preview your configuration.

Implementation contract: ReaPackLab must parse this exact REAPACKLAB-CONFIG/1 format: xURL unsubscribes without uninstalling, -URL uninstalls packages owned by that repository, and obsolete_packages=remove|keep controls obsolete package cleanup. The extension stores successfully applied versions and verifies the password using PBKDF2. The HTML alone does not change the extension. Host the file at a trusted HTTPS URL. A publicly readable password hash can be attacked offline, so a longer password is preferable even though the minimum is six characters.
